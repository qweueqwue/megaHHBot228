# Hogwarts RP Telegram Bot

Бот для общего ролевого чата по вселенной Harry Potter.

## Возможности

- генератор канонических заклинаний: учебные, боевые и запрещённые;
- дуэли игроков с HP, защитой, уклонением и ходами;
- случайные ролевые события;
- библиотека с каталогом, выдачей книг и закрытым разделом;
- баллы факультетов и история начислений;
- внутренняя магическая почта с задержкой, подписью совы и анонимными письмами.

## Запуск

1. Создайте бота через `@BotFather` и получите токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен.
3. Установите Python 3.11+.
4. Выполните:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

5. Добавьте бота в группу и выдайте ему право читать сообщения. Для корректной работы команд в группе отключите privacy mode через `@BotFather` → `/setprivacy` → Disable.

## Основные команды

`/start` — регистрация и справка  
`/house Gryffindor` — выбрать факультет  
`/spell` — случайное заклинание  
`/spell боевые` — заклинание нужной категории  
`/duel @username` — вызвать игрока  
`/accept` — принять вызов  
`/cast Expelliarmus` — применить заклинание в своей дуэли  
`/defend` — защита на текущий ход  
`/dodge` — попытка уклониться  
`/event` — создать событие вручную  
`/library` — каталог библиотеки  
`/borrow 1` — взять книгу  
`/return 1` — вернуть книгу  
`/points` — таблица факультетов  
`/award @username 10 за смелость` — выдать баллы, только администратор  
`/mail @username текст` — отправить письмо  
`/mail anonymous @username текст` — анонимное письмо  
`/inbox` — получить доставленные письма  
`/help` — полная подсказка

## Важные замечания

- Используются только заклинания, существующие в каноне Harry Potter.
- Запрещённые заклинания доступны только администратору для игровых сцен и не наносят повышенный урон автоматически.
- Для адресата письма он должен хотя бы один раз написать боту `/start`.
- Состояние хранится в файле `hogwarts.sqlite3`.
- Это готовый базовый вариант: для крупного проекта можно добавить inline-кнопки, веб-панель, роли преподавателей и Redis.
